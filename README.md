# AETHER HouseKeeper · 极简几何智能家居 Web 控制台

面向家庭平板中控（以 **iPad 横屏** 为参考基准，兼容 iPhone 与桌面端）的纯前端智能家居交互控制台。

以《底特律：变人》的极简仿生白灰几何美学为基础，突破传统方正网格，采用**七巧板大斜线拼合布局**与纯触屏 3D 按压反馈；并在「酷炫」模式下提供《赛博朋克 2077》夜之城高对比霓虹主题。

---

## 核心特性

- **七巧板大斜线拼合布局**：参数化几何生成器实时计算斜线交点，所有相邻斜边保持平行与等宽切缝，大小主次对比鲜明。
- **唯一视觉焦点**：全页仅在巨型中枢块保留一处同心三角旋转呼吸核心，其余板块极简克制。
- **4 种空间场景联动**：
  - **明亮（DAYLIGHT）**：纯净冷白灰
  - **温馨（WARM）**：暖灰石膏柔光
  - **酷炫（COOL · 2077）**：《赛博朋克 2077》深墨黑 + 赛博黄 + 电子青 + 霓虹赤红
  - **熄灯（LIGHTS OUT）**：低眩光月岩灰夜视态
- **纯触屏 3D 交互与二级菜单全缓动转场**：
  - 移除鼠标跟随，采用底层 3D 挤出厚度块与触屏按压沉降反馈。
  - 支持「精细调参（亮度/色温/窗帘开合/空调恒温）」与「安防与定时（离家警戒/睡眠倒计时/全屋同步宏）」二级视图全缓动切入。
- **非滚动 iPad 弹性自适应**：读取 `visualViewport` 自动兼容 Safari 顶部地址栏与安全区，横屏跨分辨率保持一致布局。
- **移动端低温省电优化**：零实时毛玻璃模糊、WebGL 降采样 + 智能动态限帧（静态 26fps / 触控与转场 60fps）+ 后台自动休眠。

## 快速开始

### 方式一：直接打开

项目为纯前端零构建设计，直接用现代浏览器打开 [index.html](./index.html) 即可体验。

### 方式二：启动本地静态服务器（支持手机 / iPad 局域网访问）

```bash
npm install
npm start
```

启动后终端会打印本机与局域网访问地址（默认端口 `3000`），同一 Wi-Fi 下的 iPad / iPhone 浏览器可直接访问。在 iPad Safari 中点击「分享 → 添加到主屏幕」即可获得全屏原生中控体验。

## 项目结构（纯 WebGL 2.0 分层架构）

```text
HouseKeeper/
├── index.html                  # 极简入口，仅承载全屏 <canvas>
├── src/
│   ├── config/
│   │   ├── home.config.js      # 场景、设备、滑块规格、预设、定时与宏声明式配置
│   │   └── layout.config.js    # 舞台比例、斜线锚点与七巧板拓扑声明式配置
│   ├── core/
│   │   ├── geometry.js         # 声明式拓扑求值器与多边形数学工具
│   │   └── store.js            # HomeStore 纯业务状态机、事件发布与持久化
│   ├── engine/
│   │   ├── theme.js            # 4 套场景 RGBA 浮点调色板与零 GC 插值
│   │   ├── font-atlas.js       # 1024x1024 纯白共享文字纹理图集（着色器染色）
│   │   ├── gl-renderer.js      # WebGL 2.0 批处理引擎（整帧恒定 2 次 DrawCall）
│   │   └── input.js            # 纯触控射线法多边形碰撞（嵌套按钮与滑块捕获）
│   ├── ui/
│   │   ├── primitives.js       # 3D 板块、同心三角核心、进度条、滑块等绘制原语
│   │   ├── background-layer.js # 背景斜切色块、平行斜线、波纹与扫光图层
│   │   └── views/
│   │       ├── hub-view.js        # 一级七巧板总览视图
│   │       ├── inspector-view.js  # 二级精细调参视图
│   │       └── automation-view.js # 二级安防与定时视图
│   └── main.js                 # 装配入口、动态限帧主循环与左上角调试 HUD
├── server.js                   # Node + Express 局域网本地静态服务器
├── package.json                # 项目配置与依赖
└── DESIGN.md                   # 完整设计要点与架构文档
```

更详细的设计规范与后续对接 Home Assistant / MQTT 指南请参阅 [DESIGN.md](./DESIGN.md)。
